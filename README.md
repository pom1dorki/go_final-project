# Планировщик задач (Go Final Project)

## Описание проекта

Это веб-приложение — простой и удобный планировщик задач.  
Приложение позволяет:
- Добавлять новые задачи с датой, заголовком, комментарием и правилом повторения
- Просматривать список всех задач, отсортированных по дате
- Редактировать существующие задачи
- Отмечать задачи как выполненные (одноразовые удаляются, периодические переносятся на следующую дату)
- Удалять задачи
- Поддерживает правила повторения: `d N` (каждые N дней), `y` (ежегодно), а также расширенные правила `w` и `m`

## Выполненные задания со звёздочкой

- Поддержка порта через переменную окружения `TODO_PORT`
- Поддержка пути к базе данных через переменную окружения `TODO_DBFILE`
- Поддержка всех правил повторения задач (`w` и `m` со звёздочкой)
- Аутентификация через JWT-токен (пароль в `TODO_PASSWORD`)
- Docker-образ для запуска приложения

## Запуск проекта локально

1. Установите зависимости:
   ```bash
   go mod tidy

2. Запустите сервер: 
go run main.go

После запуска приложение доступно по адресу:
http://localhost:7540
Страница входа: http://localhost:7540/login.html (пароль — значение TODO_PASSWORD).

## Запуск тестов
Обычные тесты (без аутентификации)
go test ./tests -v

Тесты с аутентификацией
TODO_PASSWORD=12345 \
Token=eyJ... (вставьте токен из ответа /api/signin)
go test ./tests -v

## Запуск через Docker

1. Соберите образ:
docker build -t todo-app .

2. Запустите контейнер:
docker run -d   --name todo   -p 7540:7540   -v $(pwd)/data:/data   -e TODO_PASSWORD=12345   todo-app

Приложение будет доступно по http://localhost:7540.
